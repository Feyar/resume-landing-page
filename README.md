# 个人简历落地页

姜飞扬的公开个人简历网站，展示职业经历、技术栈、代表项目与公开技术沉淀。

## 项目说明

- 类型：纯静态 HTML 单页
- 入口：`index.html`
- 技术：HTML、CSS、原生 JavaScript
- 依赖：无 Node.js 依赖，无构建步骤
- 数据文件：未迁移桌面目录中的 `data.json`，因为当前页面不读取该文件，避免产生重复数据源

## 本地预览

直接在浏览器中打开 `index.html` 即可预览。也可以使用任意静态文件服务器启动本地预览。

## 发布方式

项目关联 GitHub 后，由 Vercel 导入仓库根目录。向 `main` 分支推送后，Vercel 自动部署最新版本。

- Build Command：留空
- Output Directory：留空
- Framework Preset：Other / 静态 HTML
- 线上地址：首次部署后补充

## 更新注意

修改公开履历、项目名称、量化数据、联系方式或外部资源前，请先确认内容和公开范围。发布前应在桌面端与移动端检查布局、导航、主题切换、图表、外链和浏览器控制台。
